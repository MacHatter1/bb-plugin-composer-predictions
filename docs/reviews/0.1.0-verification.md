## Practical limits

Generation is a hidden BB helper using the source provider/model and its normal usage allowance. Conversation input is a bounded reconstruction including completed tool records; it is not a native Codex history fork. The editor overlay depends on BB 0.46 DOM attributes and fails closed if its own composer cannot be identified. Permission mode and a no-tools instruction do not constitute a provider-level tool-free sandbox. See [DESIGN.md](../DESIGN.md).
